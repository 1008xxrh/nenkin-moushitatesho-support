# （非公式）病歴・就労状況等申立書 サポート（試作 第1〜5章 + 過去編）

障害年金の **病歴・就労状況等申立書** を書くための**現状整理＋過去編整理ツール**です。

公開ページ：
[https://1008xxrh.github.io/nenkin-moushitatesho-support/](https://1008xxrh.github.io/nenkin-moushitatesho-support/)

---

## 開発者向け：編集するファイルについて（重要）

**`index.html` は自動生成物です。直接編集しないでください。**

- 編集する場合は `index.src.html` を編集する
- `node build-single.js`（または `npm run build`）で `index.html` を再生成する
- `npm test` は上記ビルドを自動実行してから（pretest）テストするので、`npm test` さえ通してからpushすれば `index.html` は常に最新になる

`index.html` は、ExcelJS（Excel出力に使うライブラリ）の中身を丸ごとインライン埋め込みした単一ファイル版で、これをそのまま利用者に配布・公開している（GitHub Pagesが公開する実体もこれ）。中身が160万バイト超あるため直接編集するとエディタ・コードレビューの負担が大きく、`index.src.html`（ExcelJSは外部参照のまま）と分離している。

## このツールの目的

申立書を書く前に「今どんな状況か」「過去に何があったか」を、**認知負荷をできるだけ下げながら整理**するための試作版です。

特に以下の負担を軽減することを目指しています：

- 何を書けばいいかわからない
- 時系列が頭の中でぐちゃぐちゃになる
- 現在の困りごとと過去の出来事が混ざって整理しにくい

発達障害（ASD・ADHD・知的障害など）のように、困りごとが子どもの頃から続いていて、最初の通院よりずっと前から症状があるケースにも対応しています（詳しくは「4. 記載形式の切り替え」参照）。

## 現在できること（主な機能）

### 1. 現状整理（第1〜2章）
- 現在の就労状況（働いている／働いていない）
- 仕事内容・通勤・出勤日数・勤務中の体調、不就労理由の整理
  - 初回入力時は、1問ずつ答えていく会話形式の画面で進みます（タップするとすぐ次の質問へ）。あとから内容を直したいときは、これまで通り一覧形式の画面で選び直せます。
- 日常生活の困りごと（ADL + その他）
  - 初回は同じく会話形式で1項目ずつ質問します。選ぶのが難しい項目では、そのまま「生活状況をふりかえる」画面（着替え・トイレ・食事・炊事・掃除・洗面・入浴・散歩・洗濯・買物の10項目を、場面ごとの具体的なチェックから選べる画面）へ直接移動できます。「できる／まあできる／援助があれば／できない」のどれか一つをいきなり選ぶのが難しいときの、もう一つの入口です。選んだ結果は、確認したうえで手動で取り込めます（自動では反映されません）。

### 2. 出来事・通院記録の整理（第3〜4章）
- 生活や就労に影響した出来事をカード形式で入力
- 通院期間・通院していない期間の整理
- 病院情報の登録（状況の補足メモも入力可能）

### 3. 年表への配置（第5章）
- 出来事カードを年齢帯に配置して年表化
- 「いつ頃かわからない」思い出も、自作の出来事カードとして年表に置ける（過去編）

### 4. 記載形式の切り替え（初診からの形式／生年からの形式）
- 通常は「初診からの形式」（最初の通院記録を起点に整理）
- 発達障害等で、最初の通院よりも前から困りごとがあった場合は「生年からの形式」に切り替え可能
- 「生年からの形式」では、生まれてから中学校卒業ごろまでを、就学前・小学校・中学校（記録の細かさによってはさらに細かい区分）に分けて整理できる
- プレビュー画面でいつでもワンタップで切り替えでき、切り替えるとプレビュー・Excel出力の両方に即座に反映される

### 5. 認定日ごろの状況・障害者手帳情報
- 障害認定日ごろの就労状況・日常生活状況を別途入力可能（入力しなくても空欄で出力可能）
- 表紙画面から、就労状況／生活状況（ADL）／その他の3項目に個別に入れるほか、「次へ」で先頭から通しで入力することもできます
- 就労状況は「仕事をしていた／休職中だった／仕事をしていなかった」の3択（休職中は「仕事をしていなかった」として扱われます）。仕事をしていなかった理由は、現状整理（第1〜2章）と同じ会話形式（1問ずつ・タップするとすぐ次の質問へ）で答えられます
  - 「認定日ごろの生活状況をふりかえる」画面：現在版と同じ10項目を、認定日（初診からおおむね１年６か月ごろ）を振り返る形で選べます。選択肢は認定日欄の様式に合わせて過去形（「できた」「援助があればできた」など）で表示されます。現在版と同じく、選んだ結果は確認したうえで手動で取り込めます
- 手帳の種類・等級・交付年月日・障害名

### 6. 過去編（自作の出来事カード）
- 「いつ頃かわからない」思い出も、短い言葉だけで気軽に置ける自作カード機能
- 年表に配置すると、時期が重なる通院記録の状況欄に自動で反映される

### 7. プレビュー＆Excel出力
- 紙面を模したリアルタイムプレビュー
- 公式様式（02.xlsx）への自動書き出し
- 記載件数が枠を超える場合は、続紙（04.xlsx）も自動で生成・ダウンロード

## 保存について

入力内容は**ブラウザの localStorage** に保存されます。

- 外部サーバーには一切送信されません
- 同じ端末・ブラウザで継続して使えます
- 他の端末では、そのままでは引き継げません（あらかじめ「DL保存」でファイルに書き出しておけば、そのファイルから別の端末でも復元できます）
- シークレットモード（InPrivate等）でご利用の場合、ウィンドウを閉じると内容は残りません（閉じる前に「DL保存」していない限り、後から取り戻す方法はありません）
- 端末やブラウザの設定によっては、しばらく開かない期間が続いたときや、履歴を消したとき、機種を変えたときなどに、保存内容が消えてしまうことがあります

### バックアップ（DL保存・復元）

画面下部の「DL保存」ボタンから、ここまでの入力内容をファイルとして端末にダウンロードできます。保存内容が消えてしまった場合や、続きを別の機会に行いたい場合は、そのファイルから元の状態に復元できます。

- ダウンロードされたファイルは端末に保存されるだけで、外部には送信されません
- 「DL保存」を押すたびに新しいファイルができます（同じ名前で上書きはされません）。増えてきたら古いものは消して大丈夫です
- 数日おきなど、こまめに「DL保存」しておくことをおすすめします
- **復元は「今の内容に追加」ではなく、ファイルの中身に完全に置き換わります。** 新しく入力した内容がある状態で古いファイルを読み込むと、その新しい内容は失われるのでご注意ください

## 想定している使い方

1. 現在の生活・就労状況を整理（第1〜2章）
2. 出来事・通院記録を整理し、年表に配置する（第3〜5章＋過去編の自作カード）
3. （必要なら）記載形式を「生年からの形式」に切り替える
4. 認定日ごろの状況を手書き感覚で入力（任意）
5. プレビューで確認 → Excelダウンロード
6. 必要に応じて年金事務所・社労士さんに相談しながら完成
