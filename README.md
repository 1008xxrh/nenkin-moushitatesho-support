# 病歴・就労状況等申立書 サポート（試作 第1〜5章 + 過去編）

障害年金の **病歴・就労状況等申立書** を書くための**現状整理＋過去編整理ツール**です。

公開ページ：
[https://1008xxrh.github.io/nenkin-moushitatesho-support/](https://1008xxrh.github.io/nenkin-moushitatesho-support/)

---

## このツールの目的

申立書を書く前に「今どんな状況か」「過去に何があったか」を、**認知負荷をできるだけ下げながら整理**するための試作版です。

特に以下の負担を軽減することを目指しています：

- 何を書けばいいかわからない
- 時系列が頭の中でぐちゃぐちゃになる
- 現在の困りごとと過去の出来事が混ざって整理しにくい

---

## 現在できること（主な機能）

### 1. 現状整理（第1〜2章）
- 現在の就労状況（働いている／働いていない）
- 仕事内容・通勤・出勤日数・勤務中の体調
- 日常生活の困りごと（ADL + その他）
- 不就労理由の整理

### 2. 出来事・通院記録の整理（第3〜4章）
- 生活や就労に影響した出来事をカード形式で入力
- 通院期間・通院していない期間の整理
- 病院情報の登録（状況の補足メモも入力可能）

### 3. 年表への配置（第5章）
- 出来事カードを年齢帯に配置して年表化
- 「いつ頃かわからない」思い出も、自作の出来事カードとして年表に置ける（過去編）

### 4. 認定日頃の状況・障害者手帳情報（任意）
- 障害認定日頃の就労状況・日常生活状況を別途入力可能（入力しなくても空欄で出力可能）
- 手帳の種類・等級・交付年月日・障害名

### 5. 過去編（自作の出来事カード）
- 「いつ頃かわからない」思い出も、短い言葉だけで気軽に置ける自作カード機能
- 年表に配置すると、時期が重なる通院記録の状況欄に自動で反映される

### 6. プレビュー＆Excel出力
- 紙面を模したリアルタイムプレビュー
- 公式様式（02.xlsx）への自動書き出し
- 記載件数が枠を超える場合は、続紙（04.xlsx）も自動で生成・ダウンロード

---

## まだ対応していないこと（今後の拡張予定）

- 傷病名・発病日・初診日の詳細整理（現状は空欄のまま出力されます）
- PDF出力
- 診断書との完全連動機能

---

## 保存について

入力内容は**ブラウザの localStorage** に保存されます。

- 外部サーバーには一切送信されません
- 同じ端末・ブラウザで継続して使えます
- 他の端末やシークレットモードでは消えます

---

## 想定している使い方

1. 現在の生活・就労状況を整理（第1〜2章）
2. 出来事・通院記録を整理し、年表に配置する（第3〜5章＋過去編の自作カード）
3. 認定日頃の状況を手書き感覚で入力（任意）
4. プレビューで確認 → Excelダウンロード
5. 必要に応じて年金事務所・社労士さんに相談しながら完成

## フィードバック大歓迎です

このツールは実際に使ってもらって「どこで疲れるか」「どこがわかりにくいか」を知るために公開しています。

特に以下の感想をいただけると助かります：

- 面倒に感じた質問・画面
- 何を聞かれているかわからなかったところ
- 「これも聞いてほしかった」と思った項目
- 全体でかかった時間
- 過去編（自作カード機能）の使いやすさ
